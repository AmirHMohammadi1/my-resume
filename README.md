# سایت رزومه — امیرحسین محمدی

سایت استاتیک دوزبانه (فارسی/انگلیسی) با Next.js که روی GitHub Pages **رایگان** منتشر می‌شود.

## انتشار (یک‌بار انجام می‌شود)

1. در گیت‌هاب ریپوی **Public** با اسم دقیق `AmirHMohammadi1.github.io` بساز.
2. تمام محتوای همین پوشه (به‌جز `node_modules`) را در ریشه‌ی ریپو آپلود/commit کن، روی شاخه‌ی `main`.
   (مهم: پوشه‌ی مخفی `.github` هم باید آپلود شود.)
3. در ریپو: **Settings ← Pages ← Build and deployment ← Source = GitHub Actions**.
4. تب **Actions** را باز کن؛ بعد از چند دقیقه workflow سبز می‌شود و سایت روی
   `https://amirhmohammadi1.github.io` بالا می‌آید.

از این به بعد هر commit روی `main` سایت را خودکار دوباره منتشر می‌کند.
اگر Actions خطا داد، لاگ آن را کپی کن و بفرست.

## چیزهایی که بیشتر عوض می‌کنی

| کار | فایل |
|---|---|
| ایمیل، شماره، تلگرام، لینکدین | `site.config.ts` ← بخش `contact` |
| روشن/خاموش کردن بلاگ | `site.config.ts` ← `blog: true` یا `blog: false` |
| متن‌ها (فارسی / انگلیسی) | `src/content/fa.ts` و `src/content/en.ts` |
| پروژه‌های نمایش‌داده‌شده | `src/content/projects.ts` (+ متن هر پروژه در `fa.ts` / `en.ts`) |
| رنگ‌ها و ظاهر | بالای `src/app/globals.css` (متغیرهای `--accent` …) |

فایل‌ها را می‌توانی مستقیم از سایت گیت‌هاب (آیکن مداد) یا اپ موبایل ویرایش و commit کنی.

### کلید بلاگ
`blog: false` یعنی لینک منو، صفحه‌ی فهرست و همه‌ی مقاله‌ها **کلاً از خروجی حذف می‌شوند**.
`blog: true` دوباره همه را برمی‌گرداند. بعد از تغییر commit کن تا سایت دوباره ساخته شود.

### نوشتن مقاله
برای هر مقاله دو فایل در `content/blog/` بساز (یکی برای هر زبان):

```
content/blog/اسم-مقاله.fa.md
content/blog/اسم-مقاله.en.md
```

بالای هر فایل:

```
---
title: عنوان مقاله
description: خلاصه‌ی یک‌خطی
date: 2026-10-26
tags: [Next.js, Tips]
---
```

بعد از آن متن را با Markdown بنویس. `draft: true` مقاله را مخفی نگه می‌دارد.
اگر مقاله فقط یک زبان داشته باشد مشکلی نیست؛ کلید زبان در آن صفحه به فهرست بلاگ می‌رود.
حداقل یک مقاله‌ی منتشرشده باید در بلاگ بماند (یا بلاگ را خاموش کن).

### رزومه PDF
دو فایل PDF (فارسی و انگلیسی) آماده در `public/resume/` هستند و دکمه‌ی دانلودشان روی سایت فعال است
(`resume.enabled: true` در `site.config.ts`). اگر نمی‌خواهی دکمه دیده شود، آن را `false` کن.

نکته: ایمیل و شماره‌ی تلفن **عمداً** داخل PDF نیست، چون هنوز مقدار نمونه داشتند.
بعد از وارد کردن مقدار واقعی در `site.config.ts` به من بگو تا PDFها را دوباره بسازم، یا فایل‌ها را
خودت با نسخه‌ی جدید (با همان اسم) در `public/resume/` جایگزین کن.

## اجرای محلی (اختیاری)

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # خروجی استاتیک در پوشه‌ی out/
npm run typecheck  # بررسی خطاهای TypeScript
```

نیازمند Node.js نسخه‌ی ۲۰ یا بالاتر.

## ساختار

```
site.config.ts        تنظیمات مرکزی (تماس، بلاگ، زبان پیش‌فرض)
content/blog/         مقاله‌های Markdown
src/content/          متن‌های دوزبانه و داده‌ی پروژه‌ها
src/components/       کامپوننت‌ها و بخش‌های صفحه
src/features/blog/    مسیرهای بلاگ (با کلید blog به src/app/[lang]/blog کپی می‌شوند)
src/app/              لی‌اوت‌ها، صفحه‌ها و استایل
scripts/              کلید بلاگ، sitemap، robots و صفحه‌ی ۴۰۴
.github/workflows/    انتشار خودکار روی GitHub Pages
```
